# Launcho Agent

دستیار هوش مصنوعی چندمستأجری برای فروشگاه‌های اینترنتی.
از کاتالوگ فروشگاه تغذیه می‌شود و فقط از ابزار حقیقت می‌گوید.

## وضعیت
v0.1 — پاسخ‌گو روی محتوای خود لانچو. بدون ابزار، بدون دیتابیس.

## قواعد معماری
- پایتون، زبان بک‌اند (D-001)
- مونولیت ماژولار (D-002)
- چند مدل، نقش‌محور (D-003)
