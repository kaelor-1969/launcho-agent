## بازتولید

Chrome و Playwright نصب‌شده لازم‌اند. ترمینال اول:

```powershell
python tests/widget_preview_server.py
```

ترمینال دوم:

```powershell
python tests/widget_interactions_browser.py
python tests/widget_responses_browser.py
python tests/widget_security_browser.py
python tests/widget_workflow_browser.py
```

سرور فقط frontend را ارائه می‌کند. APIها در مرورگر آزمون mock می‌شوند و هیچ درخواست واقعی AI یا ساخت فروشگاه انجام نمی‌شود.

## محدودیت‌ها و ایرادهای باقی‌مانده

- پیش‌نویس، نمونهٔ ثابت محلی است و با انتخاب‌های کاربر شخصی‌سازی نمی‌شود؛ این محدودیت در رابط اعلام شده است.
- اتصال هستهٔ جدید session، احراز هویت و adapter ساخت واقعی باقی است. هستهٔ جدید ریموت بدون تغییر حفظ شد؛ `can_create=False` است. frontend هنوز حالت قدیمی chat را مصرف می‌کند.
- گوشی واقعی، صفحه‌کلید واقعی فارسی و Safari بررسی نشده‌اند. دادهٔ ویجت با refresh پاک می‌شود.
- نصب وابستگی‌های backend با timeout از `files.pythonhosted.org` شکست خورد؛ full unittest و runner وابسته به FastAPI در این محیط اجرا نشدند. بررسی نحو فایل‌های Python انجام شد.
- یک آزمون تکرار ارسال در اجرای موازی به تأخیر ۷۰۰ میلی‌ثانیه‌ای وابسته بود. تحریک ارسال‌های تکراری در همان task مرورگر انجام شد تا زمان‌بندی ابزار دخالت نکند؛ اجرای مجدد کامل تعامل‌ها پاس شد. قفل API جداگانه با پاسخ متوقف‌شده بررسی می‌شود.
- اتصال hook قالب به سایت واقعی و تأیید شناسه و تصویر با تیم سایت است.

موبایلِ ورودی، پرداخت و دامنه قابلیت‌های منتظر اتصال نیستند؛ از محدودهٔ این مسیر حذف شده‌اند.
