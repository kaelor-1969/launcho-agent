# گزارش اجرای شبیه‌سازی محلی

تاریخ اجرا: ۲۰۲۶-۱۱-۱۱

## آماده‌سازی

محیط موجود Python 3.9.6 با نگارش نوع‌های پروژه سازگار نبود. محیط Python 3.11 ابتدا در `.venv/py311` ساخته شد. پس از در دسترس نبودن پایتون آن در مسیر موقت، محیط در `.venv/runtime311` بازسازی و پایتون در `.venv/python` نصب شد. وابستگی‌های `requirements.txt` نصب شدند. کد برنامه تغییر نکرد.

## دستور و نتیجه

```bash
.venv/runtime311/bin/python tests/check_demo.py --keep-open
```

خروج با کد صفر و نتیجه:

```text
PASS: widget assets, read-only mock, labeled offer, and retry
```

اجرای اولیه بدون `--keep-open` با کد صفر تمام شد. اجرای مجدد با دستور بالا نیز PASS داد و برای تست دستی باز نگه داشته شد. دو سرور محلی روی پورت‌های ۸۰۰۰ و ۸۰۰۱ اجرا شدند. بارگیری فایل‌های ویجت، ایجاد جلسه در حالت mock فقط‌خواندنی، نمایش پیشنهاد آزمایشی همراه لینک تعرفه، یکسان بودن پاسخ تکرار درخواست با شناسه یکسان و نمایش ندادن مجدد پیشنهاد در پیام بعدی بررسی شدند.

## محدودیت‌ها

این اجرا بدون مدل واقعی و با داده آزمایشی انجام شد. کیفیت لحن مدل، نمایش موبایل و دسکتاپ و قطع شبکه در مرورگر بررسی نشده‌اند. بررسی ارسال مجدد این اسکریپت در سطح API است؛ مشاهده حباب‌های گفتگو نیازمند تست ویجت یا مرورگر است.

## اجرای مجدد

```bash
source .venv/runtime311/bin/activate
python tests/check_demo.py
```

برای باز ماندن دمو با پاسخ‌های آزمایشی:

```bash
python tests/check_demo.py --keep-open
```

سپس `http://127.0.0.1:8001/` را باز کنید. برای بررسی مدل واقعی، تنظیمات معتبر خصوصی لازم است:

```bash
python tests/check_demo.py --env-file .env --keep-open
```

فایل‌های محیط مجازی و تنظیمات خصوصی نباید در PR قرار بگیرند. در بررسی اتصال، سؤال نیازمند مدل با خطای `503 model_unavailable` مواجه شد؛ فایل `.env` موجود نبود. سناریوهای وابسته به مدل تا فراهم شدن تنظیمات معتبر مسدودند.
