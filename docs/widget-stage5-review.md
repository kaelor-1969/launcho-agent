# گزارش مرحلهٔ ۵: حذف دریافت موبایل و پرداخت

تاریخ: ۲۰۲۶-۱۱-۰۸

## تغییرات

- ورودی شماره موبایل، تبدیل ارقام و اعتبارسنجی تلفن از renderer و demo حذف شد.
- انتخاب روش پرداخت، مبلغ و تخفیف دوره‌ها، quote، اقساط، انقضای مبلغ، درگاه و وضعیت تراکنش حذف شدند.
- دوره‌های سه‌ماهه، شش‌ماهه و سالانه به‌عنوان انتخاب اطلاعاتی باقی ماندند؛ قیمت یا تعهد مالی ندارند.
- مرور اطلاعات شماره تلفن و دادهٔ مالی ندارد. تأیید به کارت پیش‌نویس نمایشی ختم می‌شود و اقدامی برای ادامه به پرداخت وجود ندارد.
- schema فقط viewها و اقدام‌های مجاز را می‌پذیرد؛ فیلدها، اقدام‌ها و داده‌های مالی قدیمی رد می‌شوند.
- README، قرارداد adapter و راهنمای تحویل بازنویسی یا اصلاح شدند. گزارش‌های تاریخی از وضعیت جاری تفکیک شدند تا دریافت موبایل یا پرداخت، کار باقی‌مانده برای اتصال تلقی نشود.
- backend، prompt و قرارداد موجود چت تغییر نکردند.

در بازنویسی اولیه، عبور متن از pipe ویندوز باعث خرابی کدگذاری فارسی شد؛ فایل با ابزار ویرایش UTF-8 دوباره نوشته و متن فارسی در مرورگر تأیید شد.

در هر سه عرض demo، درخواست واقعی API، درخواست بیرونی، خطای JavaScript یا خطای console ثبت نشد. ذخیرهٔ localStorage خالی ماند. در تست adapter، ایجاد پیش‌نویس سه بار با یک کلید انجام شد: خطای شبکه، پاسخ فاقد confirmed:true و سپس پاسخ معتبر؛ حباب یا مرحلهٔ موفق کاذب ساخته نشد.

## اجرا و شواهد

با سرور frontend موجود، Playwright و Chrome نصب‌شده:

```powershell
python tests/widget_workflow_browser.py --base-url http://127.0.0.1:8000
python tests/widget_interactions_browser.py --transport-only
```

آزمون workflow به‌روزرسانی شد و همچنان از runner اصلی `tests/widget_browser.py` هم قابل فراخوانی است. اجرای مستقل به FastAPI نیاز ندارد.

گزارش در `artifacts/widget-stage5/report.json` و ۲۱ تصویر در همان پوشه است. تصاویر مرور دسکتاپ و موبایل، پیش‌نویس موبایل و viewport کوتاه ۳۲۰ باز و بازبینی شدند. پوشهٔ artifacts در گیت نادیده گرفته می‌شود؛ تصاویر در تحویل PR باید ضمیمه شوند.

## محدودیت‌ها و مرحلهٔ بعد

- دامنهٔ نمایشی هنوز در مسیر فعلی است؛ حذف آن، قرارگرفتن دوره اشتراک پیش از قالب و نمایش لینک پیش‌نویس طبق مسیر نهایی، مربوط به مرحلهٔ ۶ است. این گزارش انجام مرحلهٔ ۶ را ادعا نمی‌کند.
- تا آماده‌شدن بک‌اند، هیچ فروشگاه یا پیش‌نویس واقعی ساخته نمی‌شود. قابلیت پرداخت یا دریافت موبایل قرار نیست با آماده‌شدن بک‌اند فعال شود.
- بررسی‌ها با Chrome، سرور فایل‌های frontend و API شبیه‌سازی‌شده انجام شدند؛ دستگاه واقعی و Safari بررسی نشدند.
- اجرای تست‌های وابسته به FastAPI در محیط فعلی ممکن نبود، چون وابستگی uvicorn موجود نیست و نصب وابستگی‌ها قبلاً با timeout دریافت مواجه شد. این مرحله آزمون‌های مستقل frontend را اجرا کرد.
- PR، commit و push در این مرحله انجام نشدند؛ تحویل نهایی پس از مراحل باقی‌مانده است.
