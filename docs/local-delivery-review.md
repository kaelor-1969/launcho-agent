## کاتالوگ و قرارداد

صفحهٔ [فرم رسمی](https://launcho.ir/start) دریافت شد؛ عنوان هر ۲۷ صنف fixture در HTML آن وجود داشت. [صفحهٔ قالب‌ها](https://launcho.ir/#templates) ۲۶ مدخل داده داشت؛ ۲۳ مدخل نمایان دارای لینک عمومی وارد انتخاب محلی شدند. بوتیک مخفی بود؛ خودرو و ساعت لینک عمومی نداشتند و انتخاب‌پذیر نشدند. عنوان‌ها از دادهٔ صفحه گرفته شدند؛ املای URL و بزرگی/کوچکی شناسهٔ نمونه تغییر نکرد.

برای هر ۲۳ لینک عمومی پاسخ 200 ثبت شد؛ عنوان HTML همهٔ پیش‌نمایش‌ها عمومی است و صرف HTTP 200، تطابق بصری محتوای قالب را اثبات نمی‌کند. بررسی بصری تک‌تک قالب‌ها اجرا نشده است. `content/public-template-evidence.json` منبع و عنوان را نگه می‌دارد؛ هیچ شناسهٔ نمونه به عنوان شناسهٔ ثبت واقعی تأیید نشده است. پیشنهاد صنفی قضاوت توسعه است؛ کلاسیک مسیر عمومی برای همهٔ ۲۷ صنف است. داده‌های سایت‌ساز همچنان صرفاً ساختگی‌اند.

قرارداد رسمی تأییدشدهٔ ثبت در منابع تحویل‌شده پیدا نشد. اسناد `core-api-contract.md` و `widget-api-contract.md` قرارداد داخلی پروژه‌اند. در نتیجه تطبیق با API واقعی و شناسه‌های واقعی «اجرا نشده» است؛ `registrationAvailability: unverified` و `availability: unavailable` حفظ شده‌اند. هیچ ثبت‌نام، پیامک یا پرداخت واقعی انجام نشد.

## بازاجرای بررسی

```powershell
python -m unittest discover -s tests -v
node --experimental-vm-modules tests/widget_session_test.cjs
# پس از راه‌اندازی دستی دو سرویس محلی با دیتابیس پیش‌فرض:
python tests/check_local_http.py
# پس از restart mock با همان دیتابیس، پیش از اجرای دوبارهٔ تست بالا:
python tests/check_local_http.py --replay-after-restart
```

اجرای بدون فلگ VM در Node خطای `vm.SourceTextModule is not a constructor` می‌دهد؛ با فلگ، آزمون‌های جلسه و ویجت پاس شدند. نتیجهٔ نهایی پایتون در `unit-tests.log` ثبت می‌شود. قواعد تشخیص مالی همچنان محدود و قاعده‌محورند؛ قرارداد رسمی یا تشخیص معنایی مدل را جایگزین نمی‌کنند.

نتیجهٔ نهایی این اجرا: ۸۵ تست پایتون قبول، تست‌های JavaScript قبول، ۲۱ ردیف نتیجهٔ HTTP قبول، ۲۳ پیش‌نمایش عمومی با HTTP 200 و سه مدخل مخفی/بدون لینک بدون اجرا. بررسی فیزیکی قطع شبکهٔ مرورگر و اجرای روی macOS همچنان برای تحویل کامل دو دستگاه باقی است.

تغییرات این نوبت فقط در کپی `local-review` هستند؛ کپی اصلی C تغییری نکرده است. پوش، PR و ادغام جدیدی برای این اصلاحات انجام نشده است.
