# بررسی ویجت لانچو

تاریخ: ۲۰۲۶-۱۱-۰۷. در شروع git تمیز بود و AGENTS.md در پروژه و مسیر والد پیدا نشد. README و همه فایل‌های frontend، مسیرهای API و آزمون‌ها بررسی شدند.

| بخش | وضعیت اولیه | شواهد / کمبود |
| --- | --- | --- |
| loader و دکمه | ناقص | Shadow DOM، نصب تکراری و lazy موجود؛ اندازه ۵۸ و فاصله غیرقابل تنظیم |
| iframe | کامل و بررسی‌شده | حفظ حافظه، handshake، origin/source/channel، Escape و focus در آزمون مرورگر |
| ظاهر | ناقص | ارتفاع ۴۵۰، قاب چرخان و فونت بزرگ؛ جهت حباب‌ها خلاف مشخصات جدید |
| پیام و خطا | کامل و بررسی‌شده | POST /api/chat، timeout، composition و retry بدون پیام تکراری |
| اطلاعات کسب‌وکار | پیاده‌سازی‌نشده | API فقط message → reply است؛ session یا step ندارد |
| قالب | منتظر API یا اتصال بیرونی | کاتالوگ یا hook انتخاب وجود ندارد |
| دامنه | منتظر API یا اتصال بیرونی | هیچ سرویس دامنه وجود ندارد |
| مرور و ویرایش | پیاده‌سازی‌نشده | مدل ساخت‌یافته یا رابط مرور ندارد |
| ساخت پیش‌نویس | منتظر API یا اتصال بیرونی | endpoint و idempotency وجود ندارد |
| اشتراک و روش پرداخت | پیاده‌سازی‌نشده | تعرفه فقط سؤال متنی به مدل است |
| هزینه و نتیجه پرداخت | منتظر API یا اتصال بیرونی | quote، checkout و status وجود ندارند |
| آزمون و راهنما | ناقص | چت پوشش دارد؛ مراحل جدید و عرض ۳۲۰ نیازمند آزمون‌اند |

مرورگر اولیه با Chrome نصب‌شده اجرا شد؛ Chromium بسته Playwright نصب نیست. بررسی‌های نهایی و وضعیت پس از اصلاح در `widget-delivery.md` ثبت می‌شوند. سایت مقصد با HTTP خوانده شد؛ صفحات اصلی آن تغییر نمی‌کنند. هیچ درخواست AI یا عملیات فروشگاه/پرداخت واقعی در آزمون مجاز نیست.
