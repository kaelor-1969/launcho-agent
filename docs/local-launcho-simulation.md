# شبیه‌سازی محلی نصب ویجت لانچو

وابستگی‌های پروژه را از `requirements.txt` نصب کنید و تنظیمات مدل را در فایل محلی `.env` ریشه قرار دهید. برای سؤال صرفاً مربوط به هزینه، پاسخ آزمایشی بدون تماس با مدل ساخته می‌شود، ولی راه‌اندازی سرویس طبق تنظیمات پروژه همچنان مقادیر کلید و مدل را می‌خواهد.

ترمینال اول، از ریشهٔ پروژه

```powershell
python -m uvicorn app.mock_launcho:app --host 127.0.0.1 --port 8001
```

ترمینال دوم، از همان ریشه

```powershell
$env:LAUNCHO_MOCK_URL = 'http://127.0.0.1:8001'
$env:LAUNCHO_API_URL = ' '
$env:LAUNCHO_API_KEY = ' '
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

صفحهٔ [میزبان محلی](http://127.0.0.1:8001/) لودر واقعی را از پورت ۸۰۰۰ بارگذاری می‌کند. دکمهٔ گفتگو را باز کنید و بپرسید «هزینه برام زیاده، چه گزینه‌ای دارم؟». در نخستین نوبت باید برچسب پیشنهاد آزمایشی و مسیر تعرفه دیده شوند. سؤال را تکرار کنید و بررسی کنید پیشنهاد در همان گفتگو دوباره نمایش داده نشود. برای تست لحن، یک سؤال دربارهٔ راه‌اندازی فروشگاه کیف و کفش بپرسید و کوتاهی پاسخ، ارتباط گزینه‌ها با محصول و حداکثر یک سؤال پیگیری را بررسی کنید.

فایل `content/launcho-mock.json` حاوی اعداد نمونهٔ قرارداد و جشنوارهٔ ساختگی است. قیمت‌ها برای تمرین قرارداد در مسیر `GET /pricing` هستند و به مشتری نمایش داده نمی‌شوند. فهرست قالب و دسته‌بندی تا دریافت دادهٔ معتبر خالی است. حالت آزمایشی فقط روی loopback فعال می‌شود و مسیر ایجاد پیش‌نویس یا پرداخت ندارد. اتصال واقعی از تنظیمات مستقل لانچو استفاده می‌کند.

اطلاعات عمومی تأییدشده دربارهٔ قابلیت‌ها، نمونه قالب‌ها و روش راه‌اندازی، به همراه پیوند منبع در `content/launcho-public.json` قرار دارند. امکان جشنواره در پنل فروشنده با پیشنهاد خرید اشتراک لانچو فرق دارد.
