# وضعیت تحویل ویجت

محدودهٔ جاری مشتری: دریافت شماره موبایل و تمام مراحل پرداخت حذف شده‌اند. انتخاب دوره اشتراک باقی است و قیمت یا تعهد مالی ندارد. قرارداد جاری در [widget-api-contract.md](widget-api-contract.md) است.

## رفتار فعلی

- loader، iframe، ظاهر گرادیانی، تم‌ها، فونت، موقعیت و فاصله‌های قابل تنظیم حفظ شده‌اند.
- chat از API موجود `POST /api/chat` استفاده می‌کند؛ demo پاسخ‌ها را محلی شبیه‌سازی می‌کند.
- پیام‌ها و برچسب‌ها با `textContent` رندر می‌شوند؛ Enter، Shift+Enter، composition، انتظار، قفل درخواست و retry دستی وجود دارند.
- demo فقط این مسیر را دارد: نام کسب‌وکار ← دسته‌بندی ← دوره اشتراک ← قالب ← مرور اطلاعات ← تأیید ← لینک پیش‌نویس نمایشی. سؤال و بررسی دامنه حذف شده‌اند و هر چهار انتخاب قابل ویرایش‌اند.
- فرم تلفن، نرمال‌سازی شماره، روش پرداخت، مبلغ، اقساط، درگاه و نتیجهٔ تراکنش حذف شده‌اند. schema نیز قرارداد قدیمی را رد می‌کند.
- لینک پیش‌نویس فقط پس از تأیید صریح نمایش داده می‌شود؛ صفحهٔ مقصد نمونه‌ای ثابت با برچسب روشن نمایشی است و به اطلاعات واردشده متصل نیست. فروشگاه واقعی ایجاد نمی‌شود.
- ایجاد پیش‌نویس قفل همزمانی و retry با همان کلید idempotency دارد؛ تضمین سرور برای استفادهٔ واقعی هنوز فراهم نیست.

## باقی‌مانده‌ها

- بک‌اند مراحل، ذخیره و بازیابی جلسه و ایجاد idempotent پیش‌نویس هنوز موجود نیست. فقط API چت واقعی است.
- اتصال hook قالب به سایت واقعی و تأیید شناسه و تصاویر قالب با تیم سایت است.
- خطای AI با HTTP 200 و reply متنی از پاسخ عادی تفکیک نمی‌شود.
- نصب production، گوشی و صفحه‌کلید واقعی و Safari بررسی نشده‌اند. داده‌ها با refresh پاک می‌شوند.
- آماده‌سازی PR نهایی با تصاویر و فهرست ایرادها پس از تکمیل مراحل باقی‌مانده انجام می‌شود.

موبایل و پرداخت، کار باقی‌مانده برای اتصال نیستند؛ خارج از محدودهٔ این دستیارند.
