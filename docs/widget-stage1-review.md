# گزارش مرحلهٔ ۱: بررسی ظاهر demo

تاریخ: ۲۰۲۶-۱۱-۰۸ — نسخهٔ بررسی‌شده: `5c67380`

صفحهٔ `/widget/demo.html` با Chrome و Playwright اجرا شد. فایل‌های اصلی `frontend/` بدون تغییر، با یک سرور محلی Python و نگاشت `/widget/` به همین پوشه ارائه شدند. نصب وابستگی‌های FastAPI به علت timeout در دریافت از `files.pythonhosted.org` کامل نشد؛ بنابراین این گزارش، اجرای بک‌اند FastAPI یا صحت mount آن را تأیید نمی‌کند.

## شواهد

- هر شش اجرا برای demo پاسخ HTTP 200 دریافت کردند.
- فونت Vazirmatn در صفحه و iframe بارگذاری شد و جهت متن ویجت RTL بود.
- اسکرول افقی ناخواسته در صفحه و سند ویجت مشاهده نشد.
- هدر، بستن، پیشنهادهای شروع، ورودی و ارسال در هر شش حالت داخل محدودهٔ صفحه بودند.
- ابعاد پنل در دسکتاپ ۳۸۰×۴۵۰، موبایل ۳۶۶×۴۵۰ و موبایل کوچک ۲۹۶×۴۵۰ بود.
- برچسب نمایشی در ویجت دیده می‌شود؛ در عرض ۳۲۰ به دو خط می‌رود و قابل خواندن می‌ماند.
- تصاویر هر شش حالت باز، به‌علاوهٔ صفحهٔ بسته در موبایل کوچک، به‌صورت بصری بازبینی شدند.
- خطای JavaScript یا پاسخ HTTP با وضعیت ۴۰۰ به بالا ثبت نشد.
- هیچ پیام یا درخواست API ارسال نشد. تست رفتار گفتگو، mock خطاها و امنیت به مراحل بعد تعلق دارد.

## خروجی‌ها

- ۱۲ تصویر: ترکیب سه اندازه، دو تم و حالت اولیهٔ بسته/باز، در همین پوشه.
- دادهٔ اندازه‌گیری‌ها: `report.json`.
- اسکریپت بازتولید: `review.py`؛ اجرا از ریشهٔ پروژه با `python artifacts/widget-stage1/review.py`، نیازمند Playwright و Chrome نصب‌شده.

## موارد باقی‌مانده و محدودیت‌ها

- اجرای مسیر از خود FastAPI پس از فراهم‌شدن وابستگی‌ها باید بررسی شود.
- موبایل به‌صورت viewport و لمس شبیه‌سازی شد؛ گوشی واقعی، صفحه‌کلید آن و Safari بررسی نشده‌اند.
- حالت بسته فقط وضعیت اولیه است؛ چرخهٔ بستن و بازکردن و سایر تعامل‌ها در این مرحله تست نشدند.
- ایراد مسدودکنندهٔ ظاهری در حالت آغازین مشاهده نشد؛ این نتیجه شامل مراحل داخلی ساخت فروشگاه نمی‌شود.
- فایل‌های اجرایی پروژه تغییر نکردند. این پوشه طبق `.gitignore` محلی است و برای تحویل PR باید جداگانه ضمیمه یا به مسیر قابل ثبت منتقل شود.
