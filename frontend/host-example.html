نمونهٔ نصب ویجت متصل

برای شروع، دکمهٔ گفتگو را باز کنید. این صفحه به API سرویس ویجت متصل می‌شود؛ پاسخ نمایشی در آن تعبیه نشده است.

بازیابی در همین تب فعال است. تازه‌سازی، انتخاب‌ها و تاریخچهٔ معتبر را از سرور می‌خواند و تأیید تازه‌ای ارسال نمی‌کند. اگر نتیجهٔ ساخت نامعلوم بماند، رابط فقط بررسی وضعیت را اجازه می‌دهد.

این نمونه به‌معنی نصب روی سایت اصلی لانچو یا آماده‌بودن اتصال production نیست. اطلاعات پرداخت و شمارهٔ موبایل را در گفتگو وارد نکنید.

برای بررسی بدون API، از نمونهٔ نمایشی استفاده کنید.
